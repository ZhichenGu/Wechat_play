# Wechat Play · 别发到群里

中文通信恐怖短篇。生日散场篇有六位联系人，每局有一个账号被冒用。保留约 9 秒可跳过的静音开场、三条结局、个人朋友圈、语音通话字幕和聊天回执。

这个仓库是游戏的开发与 Cloudflare 部署源。界面和剧情改动直接在 `game/src/` 完成，再从本仓库构建和测试。

## 本地试玩

需要 Node.js 22.12 或更新版本。在仓库目录运行：

```sh
npm ci
npm start
```

打开 http://127.0.0.1:4183/ 。若端口被占用，可用 `npm start -- 4184`。本地预览使用固定剧情回复。构建后运行 `npm test`，覆盖六个账号各自出现在三种结构中的全员离开路径、信息送达、接应错位、致命确认、回滚和托管。

已有旧版存档且未开新版时，首页继续原局。可从「发现 → 存档与重试」切换，或直接打开 `/?party=1` 与 `/?legacy=1`。两版存档分开保存。新版从「存档与重试 → 重新开始」输入 Seed，也可在结局按相同 Seed 重玩。

## 生日散场篇 · 开发与回归

下表包含剧透，适用于剧情修订 2。六种身份各有三种查证安排，可用 Seed 0–17 覆盖。两条可行路线是「后场通道 → 东门」和「侧楼梯 → 后院门」。后院门的插销需要车边接应者配合。

| Seed | 被冒用账号 | 查证与接应重点 |
| --- | --- | --- |
| 0 | 春哥 | 对照重复语音和席瑞的记录，老潘找到本人；先处理旧群共享。 |
| 1 | 老潘 | 小卫的闭馆告示戳穿旧安排，春哥找到本人。 |
| 2 | 老金 | 出门前与老潘会合；请正义在车边找到老金并借手机确认。走后院门时提前联系正义确认插销。 |
| 3 | 小卫 | 对照重复语音和席瑞的记录，正义找到本人。 |
| 4 | 席瑞 | 小卫的当晚原始资料能核对西门旧告示；老潘找到本人。 |
| 5 | 正义 | 小卫负责楼内会合，离开房间后核验群内改口消息，再和老金确认车位。 |
| 6 | 春哥 | 对照临时路线和闭馆告示。小卫手里的原始记录要主动索取，再找老潘核验。 |
| 14 | 老金 | 先核对临时路线和闭馆告示。春哥现场复查后联系小卫补发记录，车边仍由正义核验老金。 |

对照 Seed 0 与 6 可比较重复语音与路线文件，以及主动索取资料的区别。对照 Seed 2 与 14 可比较直接查档与现场复查触发资料的区别。已有存档沿用保存的场景配置，同 Seed 重玩沿用该局对应的剧情修订。

- `game/src/party-story.js` 存放人物设定、可用配置、关卡资料和 Seed 生成。新增结构时给它配置独立证据、能实际联系的证人、两条可行路线和接应链，并加入代表性 Seed。
- `game/src/party-engine.js` 按动作结算移动、消息送达、事件和结局。增加事件时把选择写入 Seed 配置，把触发与后果放进规则，并覆盖成功、错误和补救路径。关键台词在这里随状态生成。
- `game/src/session.js` 将两版状态接到同一套聊天界面。新版存档键为 `biefadaoqunli.v2`，旧版仍用 `biefadaoqunli.v1`。
- `game/src/party-dialogue.js` 管理自然对话的人设、会话范围与输出限制。托管版沿用当前 DeepSeek 接口，关键证据和动作独立于模型。没有密钥或服务失败时，固定回复继续运行。

PT-03 试玩版入口、记录导出和试玩后问题见 [盲测指南](docs/party-playtest.md)。

15–20 分钟是首玩目标，待真人盲测计时。新语音使用合成配音，声音线索有同等文字描述。

- `game/src/` 保存界面、剧情、角色记忆和存档逻辑。
- `game/assets/` 和 `game/audio/` 包含游戏图片和音频。
- `game/assets/opening.mp4` 是新开局播放的静音竖屏动画。
- `worker/` 包含服务端 DeepSeek 接入和额度控制。 `drizzle/` 包含数据库迁移。

## 以后开放在线试玩

现有服务端支持 Cloudflare Workers 和 D1。D1 记录请求次数，剧情存档保存在玩家浏览器中。

1. 创建自己的 D1 数据库，复制 `wrangler.example.jsonc` 为 `wrangler.jsonc`，填入数据库 ID，并应用 `drizzle/` 中的迁移。
2. 运行 `npm run build`，部署 `dist/server/index.js`。可使用 Cloudflare 的 Git 集成或 Wrangler。
3. 在托管后台设置私密变量 `NPC_API_KEY` 和 `SESSION_SECRET`。前者填自己的 DeepSeek API Key，后者填独立的随机值。默认全站每天 300 次、每浏览器每天 150 次，按北京时间重置。

[Workers 配置](https://developers.cloudflare.com/workers/wrangler/configuration/) · [私密变量](https://developers.cloudflare.com/workers/configuration/secrets/) · [D1 迁移](https://developers.cloudflare.com/d1/reference/migrations/)
