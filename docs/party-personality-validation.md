# 生日散场篇 · 第二阶段人格、记忆与情绪 MVP 验收

验收日期：2026-11-20（Asia/Shanghai）

## 实现范围

本轮只增加人格、关系背景、来源记忆、规则情绪和受约束的自然表达，没有增加 AI 自主行动。Seed、证据链、路线、门锁、死亡、A/B/C 结局及存档版本保持不变。

### 人格

六名 NPC 各自拥有语言节奏、压力反应、与玩家的关系、三组朋友关系、情绪表达方式、禁用风格和两项生日聚会生活细节。系统要求模型不要写角色名、不要每句重复口头禅，也不能把稳定关系背景当成当前人员状态。

### 记忆

记忆由游戏现有消息派生，不写入新的存档字段：

- 每条短期记忆记录内容、来源人物、原始消息、是否有权知道、发生时刻、会话、确定性、置信度、纠正关系和是否允许回复使用。
- 回复上下文最多使用当前会话 10 条可用记忆；其他私聊不会进入这个上下文。
- “不是 X，是 Y”式纠正会把旧说法降至最多 0.2 置信度，并禁止继续作为回复依据。
- 长期背景来自固定人格配置；模型不能生成新的权威记忆。
- 记忆按消息和规则状态实时派生，因此读档和检查点回滚会自然恢复到对应历史，不需要提高存档版本。

### 情绪

每个角色有 0–3 的紧张、担忧、怀疑和信任值，以及 calm / wary / tense / crisis 四档表达状态。数值只由章节压力、实际收到的玩家情绪、怀疑表达和线索来源更新，只进入措辞上下文，不参与路线、行动或结局判断。

### 冒用账号

危险方能读取该账号的公开人格背景和账号实际收到的当前会话记忆，用于模仿语气；上下文不会提供真人当前地点、其他私聊或未送达证据。真实人物状态也不会因设备位置自动进入账号记忆。

## 回复处理流程

1. 规则引擎先生成符合角色的本地安全回复。
2. 仅普通社交消息进入 DeepSeek；关键剧情台词和明确动作仍由规则直接处理。
3. 模型收到静态人格、当前情绪、当前会话记忆及带来源的只读事实。
4. 输出必须是一至两句，并附所使用的记忆 ID。
5. 未授权记忆、人物位置/到达等错误事实、伪造通知和行动结果会被拒绝。
6. 模型格式错误、越权或 API 失败时，保留第一步的人物化本地回复。

## 匿名人物辨识测试

已生成只显示情境和匿名 A–F 回复的测试稿，以及单独答案文件。测试稿中的 22 条是通过审核的真实模型回复，2 条是保护回退后的人物化本地回复。

当前尚未由未参与开发的人完成，因此没有“陌生测试者辨识率”。自动风格线索 63.6% 只能作为工程观察，不能代替真人匿名辨识。

建议至少邀请 3–5 名不知道人格配置的人独立完成，记录：逐条身份猜测、判断依据、最难区分角色、模板感、角色辨识把握和是否会仅凭语气信任账号。重点指标是六分类准确率及角色间混淆矩阵。

## 剩余风险

1. 人格线索在紧张情境最明显，普通聊天和纠正记忆场景仍有部分“统一安慰/统一追问”的感觉。
2. 模型偶尔会从长期背景主动带出雨伞、蛋糕等细节；这些不是权威剧情事实，但可能显得转话题，需要真人测试判断频率是否合适。
3. 记忆纠正目前覆盖明确的“不是 X，是 Y”表达；更隐晦的反悔、反讽或跨多轮纠正会保守处理。
4. 情绪是可解释的四变量规则模型，不是长期心理模拟；它不会自动形成关系门槛。
5. 24 次真实调用只证明本批样本结果，不能保证长期零幻觉或六人始终可辨。
