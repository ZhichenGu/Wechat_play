# 《别发到群里》第二阶段后 2.5 轮体验与安全验证

验证日期：2026-11-20（Asia/Shanghai）

## 验证范围

- 保留第二阶段人格、来源记忆、纠正链和规则情绪系统。
- 没有开发危险方自主策略。
- 没有改变 Seed、证据链、路线、门锁、存档版本、死亡条件或 A/B/C 结局。
- 原匿名人物辨识测试稿与答案未改动；本轮没有用模型自评冒充真人辨识结果。

本轮只做了两项小修：明确表达“缓过来、没那么慌”后，旧的紧张表达不再永久叠加担忧；玩家纠正信息时，角色先前复述过的旧值也会一并停止作为可用记忆。两项均通过新增离线回归。

最终顺序回归为 73/73 通过，构建与差异格式检查通过；Seed 0–17 双路线通关、公开资源隔离和 API 配额测试均保持通过。此前并行运行构建与测试时，生成资源文件被同时读写造成过一次临时语法错误；改为顺序执行后无法复现，确认不是产品代码失败。

## 审核拒绝分布

| 原因 | 次数 |
| --- | ---: |
| `PARTY_SCHEMA` | 12 |
| `PARTY_FACT_GUARD` | 2 |
| Provider 返回 JSON 不合法 | 2 |

当前严格格式保证了安全，但 16.7% 的回退率会在长对话中暴露固定本地句式，尤其会放大席瑞的重复感。

## 最值得优先优化的三个问题

1. **人格锚点频率过高。** 老潘、老金、正义需要“冷却”机制，同一关注点在最近两三轮出现后应降低再次使用概率，让人格更多体现在判断角度和句式节奏，而不是关键词。
2. **长对话回退过于可见。** 保持事实审核不变，但可以安全规范化三句短回复为前两句，并对缺少记忆引用的纯情绪回复采用更细的审核，减少整段回退。
3. **通用安慰结构仍然趋同。** “你先/慢慢说/我听着”需要按人物拆成不同反应路径，例如老金问可核对对象、小卫先确认玩家感受、席瑞回到时间线，但不应每轮重复同一关注点。

## 是否进入第三阶段

安全条件基本满足：96 次真实调用中越权成功、状态篡改、跨私聊泄露和纠正后旧值复用均为 0。

体验门槛尚未满足，不建议现在进入危险方自主策略开发。至少应先完成一次小规模人格去模板优化，并让 3–5 名未参与开发的人完成现有匿名人物辨识测试。只有真人六分类准确率、混淆角色和模板感有实际数据后，才能判断“熟悉说话方式但不能仅凭语气信任”的恐怖体验是否成立。
